# Network-sniffer-tool
PacketView Pro is designed as a user-friendly GUI-based packet analyzer that allows users to monitor live traffic, filter packets, and detect potential threats.

Steps to run this tool
1. Double click the tool and give run as administrator, then the tool will open.
2. Choose Interface wifi or ethernet.
3. Then click start capture then the tool will capture network packets
4. Then after capturing packets click stop capture
5. If you want to filter the packets then there is an option for it
6. After capturing if you want to export the packets then the export option is there CSV(text file format) and PCAP(which exported packets can be opened using other tools like wireshark)
